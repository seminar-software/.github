## איך עובדים

הפעולות כאן נעשות באתר, בלי להתקין כלום. מי שלא רואה את הריפוז הפרטיים צריכה קודם לאשר את ההזמנה במייל.

### להוריד

קובץ אחד: נכנסות לקובץ ולוחצות על החץ למטה, ליד Raw.

מקצוע שלם: בריפו של המקצוע לוחצות **Code** ואז **Download ZIP**. זה מוריד רק את המקצוע הזה.

מורידות רק את מה שצריך עכשיו. כשנגמר, מוחקות את התיקייה מהמחשב. העותק נשאר ב-GitHub.

### להעלות

1. נכנסות לריפו של המקצוע
2. פותחות את תיקיית השבוע, למשל `05-08.11-14.11`
3. **Add file** ← **Upload files**
4. גוררות את הקובץ
5. כותבות הודעה קצרה, למשל "שיעור לולאות"
6. **Commit changes**

תרגיל קוד נפתח כתיקייה בתוך השבוע, למשל `05-08.11-14.11/2026-11-08-loops/`.
כדי ליצור תיקייה: **Add file** ← **Create new file**, ובשם הקובץ כותבות `2026-11-08-loops/README.md`.

### לשנות

1. פותחות את הקובץ
2. לוחצות על העיפרון
3. עורכות
4. כותבות מה השתנה
5. **Commit changes**

שיעורי בית, מבחנים ומערכת שעות נערכים בריפו [class](https://github.com/seminar-software/class): `homework.md`, `exams.md`, `schedule.md`.
בתחילת שבוע מחליפות את התאריכים בשיעורי הבית ומוחקות מטלות ישנות. אחרי הגשה מחליפות ⬜ ב-✅.

למחוק קובץ: פותחות אותו, לוחצות על שלוש הנקודות, **Delete file**, ואז **Commit changes**.

### כללים

- שם קובץ מתחיל בתאריך, ואז נושא: `2026-11-08-נושא.pdf`. ככה הקבצים מסתדרים לפי הזמן.
- קובץ של שיעור נכנס לתיקיית השבוע, בריפו של המקצוע.
- כל אחת מעדכנת רק את המקצוע שלה.
- הודעת השמירה קצרה ומסבירה מה עלה או מה השתנה.
- לא מעלים `node_modules`, `.venv`, `bin`, `obj`, `.vs`, קבצי `.env`, סיסמאות או מפתחות.
- ב-GitHub Desktop: לפני שמתחילות עושות **Pull**, ואחרי השמירה **Push**.
